# サンプル解析・修正・動作評価（2026-10-02）

## 方法

提供EPUBから85段落・3,070文字を選択。冒頭の双子の会話、括弧なし心内語と
明るく振る舞う会話の交互出現、別人物の回想への視点切替の3範囲を本文で確認した。
この会話のフロンティアモデルが各段落の意味を読んで注釈を作成し、応答JSONとして
CLIへ取り込んだ。外部LLM APIは呼んでいない。自動APIの速度・費用・推定精度の
評価ではない。また、同じモデルが注釈とレビューを担当しており、独立した人手正解
との比較ではないため「話者正解率100%」等は主張しない。

書籍本文、注釈JSON、EPUBはGitHubへ含めない。再配布可能なテストは合成文のみ。

## 実測結果

| 項目 | 結果 |
|---|---:|
| 対象 | 85段落 / 3,070文字 / 4バッチ |
| 地の文 | 50 |
| 会話 | 19 |
| 心内語 | 11 |
| 見出し | 4 |
| 沈黙 | 1 |
| 初回の確認対象 | 6 |
| 個別話者が未確定 | 2（推測で確定しない） |
| 明示的レビュー後の音声ジョブ | 80 |
| 除外記録 | 見出し4 + 沈黙1 |
| ジョブへ保持されたルビ | 41 |

最初のplanはready=false、jobs=0で、6件のレビュー待ちを検出した。
沈黙1件、自由間接話法と心内語の境界3件を個別にレビューした。
未確定な相槌2件は候補を保持し、今回の試験用演出としてナレーター代読を指定。
指定後はready=true、blockers=0、jobs=80。スバル/レム/ラム/語り手の4つの固定
voice設定を用い、会話と心内語で同じ人物のvoiceが変わらないことを確認した。
voiceのproviderはevaluation-only。実際のTTSを呼び出した結果ではない。

原文に対して全85段落の被覆、80ジョブ＋5除外の台本被覆、文字順序、ルビの
親文字と文字位置をプログラムで照合。全て一致した。これは構造整合性であって、
意味判定の正解率ではない。

## 発見した問題と修正

| 問題 | 修正・確認 |
|---|---|
| 心内語のkindがTTS計画で消える | kindをジョブに保持。会話/心内語が同一voiceであることを検証 |
| ルビが親文字位置を持たない | 出現ごとのstart/endを保持。ジョブ内位置へ変換。同じ親文字に別の読みがある場合もテスト |
| 文字数のみの分割がルビを切る | 句読点優先、ルビ内部は分割禁止。上限より長いルビはエラー |
| 記号だけの沈黙が発話として通る | possible_silenceとして確認待ち。沈黙は除外記録へ |
| 話者確信度が高いだけで演技が強くなる | 感情/話し方の確信度を分離。不確かな演技はレビュー。サンプルの根拠のない「小声」を撤回 |
| 未確定話者に適当な人物を付けないと先へ進めない | 推定unknownを保持した明示的・内容拘束付きの代読指定。標準は停止 |
| review.jsonから判断理由/候補が落ちる | kind/候補/理由/演技/レビュー理由を保持 |
| サンプル範囲の飛びを連続した文脈として扱う | sample_groupで文脈を分離 |
| prepareとanalyzeでbatch設定がずれる | 設定を保存・再利用。不一致は停止 |
| 同じ長さの別原文に古い応答を取り込める | 本文/範囲/プロンプトをrequest_digestに結び付けて照合 |
| 再解析失敗後に以前の完成台本が残る | 再実行前に完成物を無効化、成功batchだけ再利用 |
| voice辞書の後変更が既存ジョブにも波及する | voice設定のdeep copyでスナップショット化 |

## 再帰テスト

`python -m unittest discover -s tests -p test_audiobook_script.py -v`

13件通過。CLIの別プロセス実行を含む。主な拒否テストは、原文改変、欠落/重複、
存在しない根拠、未登録人物、不正確信度、台本対象範囲の変更、古い取り込み応答、
設定違い、承認後の内容変更、指定なしの不明話者、ルビの途中分割。
compileall / git diff --checkも通過。

## 結論と残る評価

サンプルについて「意味注釈→検証→個別レビュー→生成計画」の一連の動作を完了。
音声そのものの聴取評価、フロンティアAPIでの自動推定再現性、全巻精度、ローカル
モデル比較は未実施。自由間接話法の読み分けは演出方針を含み、今回の判断を唯一の
正解としない。TTS選定後は発音、声質の持続性、演技、沈黙の長さ、音声連結を評価する。
